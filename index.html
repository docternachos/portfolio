{ about }

I'm Smoggly, a developer who splits my time between two very different corners of the web. On one side, I write clean, structured HTML and build front-end interfaces that just work. On the other, I hop into Roblox Studio and script gameplay systems in Lua.

I like the contrast — one day it's semantic markup and layout precision, the next it's rigging up game loops, leaderboards, or shop systems for a Roblox project. Both scratch the same itch: taking a blank file and turning it into something people can actually use.

This site is a running log of what I've been building on both fronts — swap between the tabs above to browse either side of the stack.
